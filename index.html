Megawide Apps

Planners Dashboard, Procurement, Engineering and Bids in one app. Each app always opens its latest version and remembers your login.

Windows

Download .exe

Run the installer. If Windows SmartScreen shows "Windows protected your PC", choose More info → Run anyway. The app then keeps itself up to date.

Mac

Download .dmg

Open the file and drag Megawide Apps into Applications. The first time, right-click the app → Open, then Open again.

Android

Download .apk
  1. Tap the download link above and open the file when it finishes.
  2. If asked, allow your browser to install unknown apps (Settings shows the switch).
  3. Tap Install. To update later, download and install again — your logins stay.

iPhone & iPad

The iPhone app is not available to download yet — Apple only allows a link install once the company's Apple Developer account is set up.

Until then, add each app to your home screen. It opens full screen, like an app, and remembers your login:

  1. Open the app in Safari: Planners Dashboard, Procurement, Engineering, Bids.
  2. Tap the Share button, then Add to Home Screen.
